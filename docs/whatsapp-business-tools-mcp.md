# WhatsApp Business Tools MCP — הגדרה

שרת MCP רשמי של Meta שמאפשר לסוכן AI / עוזר ב-IDE לנהל ולדבג אינטגרציה של
WhatsApp Business Platform (Cloud API) ממקום אחד.

## מה השרת עושה

לפי התיעוד של Meta, השרת מאפשר לסוכן:

- לגלות את העסקים וחשבונות ה-WhatsApp שאתה מנהל
- לחבר ולרשום מספרי טלפון (onboard, אימות OTP, רישום ל-Cloud API)
- ליצור ולנהל תבניות הודעות (message templates)
- להגדיר webhooks ולבדוק אותם
- לשלוח הודעות (כולל הודעות בדיקה)
- לאתר בעיות בקונפיגורציה

השרת פועל **בשמך**, על האפליקציות והעסקים שאתה מנהל — כלומר ההרשאות שלך
בחשבון ה-Meta הן ההרשאות שלו.

## סטטוס

השרת בהשקה הדרגתית ובבטא: יכול להיות שהוא עדיין לא זמין בחשבון שלך, והממשק
עשוי להשתנות. תאריך עדכון התיעוד שנבדק: 3 בספטמבר 2026.

## אזהרת הרשאות ומגבלות

זה **לא** כלי לקריאה בלבד. שליחת הודעות ורישום מספרי טלפון הן פעולות אמיתיות
עם השפעה חוצה-מערכות ולפעמים עלות. המלצות:

- **התחל מול משאבי הבדיקה.** כשמתחילים עם Cloud API נוצרים אוטומטית WABA
  ומספר טלפון של בדיקה, עם messaging limits מרוככים וללא צורך ב-payment
  method לשליחת תבניות.
- השתמש ב-access token עם ההרשאות המינימליות הנדרשות.
- לעולם אל תשמור טוקן ב-git — ראה `.env.example` ו-`.gitignore`.

### שים לב ל-rate limit

ברירת המחדל היא **200 בקשות בשעה** per app per WABA (5,000 ל-WABA פעיל עם
מספר רשום). המגבלה חלה בדיוק על ה-endpoints שה-MCP ייגע בהם — `/phone_numbers`,
`/message_templates`, `/subscribed_apps` ו-`/<WABA_ID>` עצמו. סוכן שנכנס ללופ
של גילוי או ניסיונות תיקון יכול לשרוף את המכסה במהירות.

פרטים מלאים, כולל pair rate limit של הודעה אחת כל 6 שניות לאותו משתמש:
[סיכום הפלטפורמה](whatsapp-business-platform-overview.md).

### מדיניות

Meta אוסרת שימוש בכלי צד-שלישי לא מאושרים. זה שיקול לטובת ה-MCP הרשמי מול
מימושי קהילה שמעטפים את Cloud API.

## התקנה

1. השג את כתובת השרת מהתיעוד של Meta (הדף כולל כפתור "Copy for LLM").
2. העתק את `.mcp.json.example` ל-`.mcp.json` והכנס את הכתובת.
3. הפעל מחדש את הסשן והשלם את האימות מול Meta (ראה "פתור בהמשך" — שיטת
   האימות של השרת עדיין לא אומתה).

```bash
cp .mcp.json.example .mcp.json
# ערוך את השדה url
```

לאימות מבוסס טוקן (אם השרת דורש זאת במקום OAuth), הוסף header:

```json
{
  "mcpServers": {
    "whatsapp-business-tools": {
      "type": "http",
      "url": "<SERVER URL>",
      "headers": {
        "Authorization": "Bearer ${WHATSAPP_ACCESS_TOKEN}"
      }
    }
  }
}
```

## פתור בהמשך

- [ ] כתובת השרת המדויקת — לא הוכנסה. `developers.facebook.com` חסום ע"י
      מדיניות ה-egress של הסשן, ולכן הכתובת לא אומתה מול המקור הרשמי.
- [ ] האם האימות הוא OAuth או Bearer token — לא אומת. הפלטפורמה בכללה
      משתמשת ב-OAuth access tokens עם permissions, אבל לא אומת כיצד השרת
      עצמו מבקש אותם.
- [ ] רשימת הכלים המדויקת שהשרת חושף (שמות ה-tools) — לא אומתה.

אין להשלים את הפרטים האלה מזיכרון או מניחוש; יש לקחת אותם מדף התיעוד.
